SPECIFICATION / ARCHITECTURE

About {{ app_name }}

An offline-capable, editorial-grade typographic layout utility built with Python, Flask, Pillow, HTML5 Canvas, and vanilla JavaScript.

A

Design Philosophy

{{ app_name }} is designed as a restrained graphic design instrument rather than a decorative dashboard. The interface uses only warm off-white (#F5F3EF), near-black (#171717), and neutral structural rules (#D8D5D0) so the artist's typography and palette remain the sole visual focus.

B

Deterministic Geometry Engine

Image silhouettes are converted into normalized binary masks backed by a two-dimensional summed-area integral table for constant-time overlap evaluation. Preview rendering on the HTML5 Canvas and high-resolution server exports share identical layout coordinates and font metrics.

C

Privacy & Local Execution

All image processing, silhouette extraction, text measurement, and vector/raster rendering execute locally. Uploaded images are validated, isolated to the active browser session, and never transmitted to external services or third-party APIs.

D

Default Prototype Configuration

Default artwork settings initialize with Space Grotesk, 66 px reference box width, 4 px horizontal and vertical spacing, Random palette distribution, and Silhouette contour fitting.
